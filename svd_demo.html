What Is Inside?

The computer stores this beautiful image as just numbers? 🤯

Every single pixel is one number from 0 (black) to 255 (white). Nothing else — pure math!

This image = 128 × 128 = 16,384 numbers

Full HD photo = 1920 × 1080 = 20,73,600 numbers!

Can we store the same image with far fewer numbers?
That's exactly what SVD does!

U — Left Patterns

Captures horizontal structure of the image. Column vectors are orthonormal — the "horizontal building blocks".

Σ — The KEY Matrix ⭐

A diagonal matrix. Each σ₁ ≥ σ₂ ≥ … ≥ 0 tells us how important each pattern is. We use K to decide how many to keep!

Vᵀ — Right Patterns

Captures vertical structure. Row vectors are also orthonormal — the "vertical building blocks" of the image.

STEP 04 — THE IMPORTANCE SCORE
NOT ALL SINGULAR VALUES ARE EQUAL
The key insight: Singular values σ₁ > σ₂ > σ₃ > … drop off very fast. The first few carry 90% of the image info. The rest is mostly noise — we can throw it away!

STEP 06 — THE BIGGER PICTURE
SVD POWERS THE REAL WORLD
📱
Photo Compression
JPEG photos on your phone use a cousin of SVD (the DCT): keep the strong components, drop the weak ones.
🎬
Video Streaming
Video codecs apply the same "keep the top components" idea to every frame, so streaming works on slow internet.
😊
Face Recognition
SVD finds "eigenfaces" — a few key patterns from which faces can be described and compared.
🏥
Medical Imaging
Low-rank (SVD) methods help remove noise and speed up MRI reconstruction from fewer measurements.
🔍
Recommendations & Search
Matrix factorisation (famous from the Netflix Prize) and Latent Semantic Analysis use SVD to find hidden patterns in what people watch and search.
🛰️
Satellite Imaging
Hyperspectral satellite images have hundreds of colour bands. SVD/PCA reduces them to a few key components.
